云驿 项目结构 v1.1.1 (2026-07-26)
云驿GUI.vcxproj                         GUI 桌面客户端项目 (WebView2)
云驿.vcxproj                             服务端项目 (Relay + HostAgent)
│
├─ NetEngine/                           静态库 — 三个角色共用，不含业务逻辑
│  ├─ Director.h/.cpp              全局单例，引擎唯一门面 (pimpl)
│  │                                 + touchRoomHeartbeat() / findRoomByControlSession()
│  ├─ Ref.h/.cpp                   引用计数基类
│  ├─ Scheduler.h/.cpp             定时器调度 — 心跳/超时/重连退避
│  ├─ Session.h/.cpp               TCP 会话基类
│  ├─ TransportCore.h/.cpp         IOCP 重叠 I/O (IPv4+IPv6 双栈)
│  │                                 + configureKeepalive(30s/10s) 死连接检测
│  ├─ TlsPskContext.h/.cpp         OpenSSL TLS-PSK 封装 (memory BIO + std::mutex)
│  ├─ FrameCodec.h/.cpp            控制帧编解码 (大端序)
│  ├─ FrameDispatcher.h/.cpp       按帧 type 注册/分发处理器
│  ├─ TunnelManager.h/.cpp         隧道生命周期 + totalBytesRelayed()
│  ├─ PortPool.h/.cpp              端口池自动分配/回收
│  ├─ NetUtil.h/.cpp               双栈网络工具 (createSocket/fillAddr)
│  ├─ ResourcePool.h                     高频对象复用池 (模板类, header-only)
│  ├─ AutoreleasePool.h/.cpp        延迟释放池
│  └─ NetEngine_H.h                       总头文件
│
├─ app/                                 业务逻辑层 — 按角色链接 NetEngine
│  ├─ common/
│  │  └─ Config.h/.cpp               全局配置 — 公网IP/端口范围/心跳/keepalive
│  ├─ component/
│  │  ├─ RoomRegistry.h/.cpp        房间注册表 + 超时检测 (心跳同步 ✓)
│  │  ├─ ControlChannel.h/.cpp      控制连接状态机 + 心跳 + 重连
│  │  │                                 + registerRoomAsync() 异步等待 ACK
│  │  └─ ConnectionCode.h/.cpp      连接码生成/解析 "IP:Port"
│  ├─ gui/
│  │  └─ main.cpp                      Win32 + WebView2 无边框窗口宿主
│  ├─ relay/
│  │  ├─ RelayApp.h/.cpp              中继服务器主程序 (引擎 + HTTP)
│  │  │                                 + checkStaleRooms() RoomRegistry 超时清理
│  │  ├─ HttpApiRouter.h/.cpp         REST API 路由 (RoomRegistry 同步)
│  │  └─ webview/
│  │     └─ yunyi.html                  WebUI SPA (双角色: relay/host 自适应)
│  ├─ hostagent/
│  │  └─ HostAgentApp.h/.cpp          房主端 (数据隧道 + HTTP 服务器)
│  │                                    + /api/v1/rooms 通过 REGISTER 帧创建
│  └─ main.cpp                      CLI 入口 (--relay / --host)
│
├─ third_party/                         已集成第三方库
│  ├─ httplib/         httplib.h           cpp-httplib HTTP 服务器 (双端共用)
│  ├─ nlohmann_json/  json.hpp            nlohmann/json 序列化
│  └─ openssl/         include/ + lib/     OpenSSL 3.x (libssl + libcrypto)
│
├─ tools/                               工具脚本
│  ├─ test_tunnel.py                           数据隧道端到端测试
│  └─ installer.nsi                            NSIS 安装包脚本
│
├─ webview2-sdk/                        Microsoft Edge WebView2 SDK
│
├─ docs/                                设计文档
│  ├─ Document.md                              架构设计文档
│  ├─ protocol.md                              控制帧协议规范
│  ├─ rest-api.md                              REST API 手册 (含双角色 + 新字段)
│  ├─ director-api.md                          Director 公开接口手册
│  └─ CHANGELOG.md                             开发日志 (v1.1.1 架构修复)
│
└─ SVG/                                 蓝图 / 架构图
   ├─ 引擎架构图.html                           项目结构骨架 (当前文件)
   ├─ 引擎接口蓝图.html                         模块接口 + 调用关系
   └─ 前端接口蓝图.html                         WebUI ↔ REST API
