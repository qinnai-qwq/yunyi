云驿 项目结构 v1.2.2 (2026-08-08)
云驿GUI.vcxproj                         GUI 桌面客户端项目 (WebView2)
云驿.vcxproj                             服务端项目 (Relay + HostAgent)
│
├─ core/                                 Core.lib — 平台/协议层，纯技术无业务 (可开源)
│  ├─ include/yunyi/core/               头文件 (命名空间 yunyi/core)
│  │  ├─ eventloop/  INetEventLoop.h, TransportCore.h  IOCP 异步 I/O (双栈)
│  │  ├─ tls/       TlsPskContext.h          OpenSSL TLS-PSK (memory BIO)
│  │  ├─ protocol/ FrameCodec.h            控制帧编解码 (大端序)
│  │  ├─ net/      NetUtil.h               双栈网络工具
│  │  ├─ pool/     PortPool.h, ResourcePool.h  端口池 + 对象复用池
│  │  ├─ log/      Logger.h                日志单例
│  │  └─ util/     ConnectionCode.h, StunClient.h  连接码 + STUN
│  └─ src/                                实现 (与 include 同域)
│
├─ framework/                             Framework.lib — 引擎风格编程模型 (可开源)
│  ├─ include/yunyi/framework/          头文件 (命名空间 yunyi/framework)
│  │  ├─ engine/   Director.h, Scheduler.h, FrameDispatcher.h  引擎门面/调度/帧分发
│  │  ├─ session/ Session.h, TunnelManager.h   会话 + 隧道管理
│  │  ├─ channel/ ControlChannel.h          六状态控制连接状态机
│  │  ├─ p2p/     P2PTunnel.h, P2PCoordinator.h  打洞隧道 + 协调接口
│  │  ├─ lifecycle/ Ref.h, AutoreleasePool.h  引用计数/释放池
│  │  └─ udp/     ReliableUdpChannel.h       可靠 UDP (打洞数据面)
│  └─ src/                                实现 (与 include 同域)
│
├─ app/                                 业务逻辑层 — 角色逻辑，闭源
│  ├─ common/
│  │  └─ Config.h/.cpp               全局配置 — 公网IP/端口范围/心跳/keepalive
│  ├─ component/
│  │  ├─ RoomRegistry.h/.cpp        房间注册表 + 超时检测
│  │  └─ P2PCoordinatorWinHttp.h/.cpp P2P 协调服务器客户端 (winhttp)
│  ├─ gui/
│  │  └─ main.cpp                      Win32 + WebView2 无边框窗口宿主
│  ├─ relay/
│  │  ├─ RelayApp.h/.cpp              中继服务器主程序 (Core+Framework + HTTP)
│  │  ├─ HttpApiRouter.h/.cpp         REST API 路由 (RoomRegistry 同步)
│  │  └─ webview/
│  │     └─ yunyi.html                  WebUI SPA (双角色: relay/host 自适应)
│  ├─ hostagent/
│  │  └─ HostAgentApp.h/.cpp          房主端 (数据隧道 + HTTP 服务器 + P2P)
│  └─ main.cpp                      CLI 入口 (--relay / --host)
│
├─ Core.vcxproj / Framework.vcxproj      静态库工程
├─ 云驿.vcxproj                        主 exe (链接 Framework.lib + Core.lib)
│
├─ third_party/                         已集成第三方库
│  ├─ httplib/         httplib.h           cpp-httplib HTTP 服务器 (双端共用)
│  ├─ nlohmann_json/  json.hpp            nlohmann/json 序列化
│  └─ openssl/         include/ + lib/     OpenSSL 3.x (libssl + libcrypto)
│
├─ webview2-sdk/                        Microsoft Edge WebView2 SDK
│
├─ docs/                                设计文档
│  ├─ Document.md                              架构设计文档
│  ├─ protocol.md                              控制帧协议规范
│  ├─ rest-api.md                              REST API 手册
│  ├─ director-api.md                          Director 公开接口手册
│  └─ CHANGELOG.md                             开发日志
│
└─ SVG/                                 蓝图 / 架构图
   ├─ 引擎架构图.html                           项目结构骨架 (当前文件)
   ├─ 引擎接口蓝图.html                         模块接口 + 调用关系
   └─ 前端接口蓝图.html                         WebUI ↔ REST API
